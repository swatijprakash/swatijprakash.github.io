# Swati Prakash — Portfolio Website

A responsive single-page portfolio built with plain HTML, CSS, and JavaScript. No build tools or frameworks required.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — layout, colors, responsive design, and animations
- `script.js` — mobile navigation, reveal-on-scroll effects, footer year, and copy-email interaction

## Preview locally
Open `index.html` in a browser. For a local server, run `python -m http.server 8000` in this folder and open `http://localhost:8000`.

## Publish to GitHub Pages
1. Download/clone your existing repository and keep a backup of its current files.
2. Copy `index.html`, `style.css`, and `script.js` into the repository root (or adjust the CSS/JS paths if you place them in subfolders).
3. Check all content, especially education, years of experience, certifications, and contact details.
4. Commit and push to the branch configured for GitHub Pages.
5. In the repository settings, verify **Settings → Pages** points to the correct branch and root folder.

## Before publishing
- Add your resume PDF if you want a download button.
- Add links to LinkedIn/GitHub and the original certification badges if you want them shown.
- The portfolio summarizes project work at a high level. Ensure all descriptions are appropriate for public sharing.
- This template does not include a backend contact form; email and phone links open the visitor's email/phone app.
- The fonts load from Google Fonts; system fallbacks are included.
